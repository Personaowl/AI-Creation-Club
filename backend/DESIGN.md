# AI Creation Club 作品平台后端设计

AI Creation Club 作品平台提供登录后的竞赛作品展示。作品是浏览、投稿、审核、上架和下载授权的基本单位。一件作品可以包含多份演示文稿、PDF、音视频和源码文件。

## 账号与登录

- 首次部署初始化一个管理员账号。初始密码由部署者设置，管理员可以修改自己的密码。
- 普通成员使用管理员发放的账号登录。管理员可以创建账号、重设密码、停用账号和重新启用账号。普通成员可以修改自己的密码。
- 回收账号时停用登录并撤销旧会话。投稿归属、作品和审核记录仍关联原账号。重新发放账号时先设置新密码，再启用账号。
- 管理后台只允许管理员进入。作品列表、详情、预览和下载都要求有效账号。前后端同域部署，采用 Django 会话 Cookie，写入操作同时校验 CSRF 令牌。 [Django 认证](https://docs.djangoproject.com/en/5.2/topics/auth/) · [DRF 会话认证](https://www.django-rest-framework.org/api-guide/authentication/#sessionauthentication)

## 作品与附件

展示页上每件作品占一张卡片，显示作品名称、简介和附件类型。进入详情后可查看已填写的比赛和团队信息，并切换作品附件。投稿时先建作品，再为同一件作品添加附件，最后整件提交审核。

| 数据 | 记录内容 |
| --- | --- |
| 账号 | 用户名、角色、启用状态 |
| 作品 | 标题、简介、比赛名称、团队名称、团队成员、作者、审核状态、上架状态、原件下载开关 |
| 作品附件 | 所属作品、原文件名、类型、大小、私有存储位置 |
| 管理记录 | 审核、上架、下架和下载开关变动的操作者、时间及审核意见 |

## 审核和上架

1. 作者创建草稿并添加附件。比赛名称、团队名称和团队成员可选填。提交后进入待审核，作品资料和附件暂时锁定。作者可在审核完成前撤回投稿，保留资料和附件并回到草稿，编辑后可重新提交。
2. 管理员可以查看待审核作品和附件，选择通过或退回。退回时填写原因，作者可修改后整件重新提交。
3. 审核通过后，管理员决定是否上架，以及是否开放原件下载。通过审核时默认保持下架，下载默认关闭。
4. 管理员可以下架已展示的作品。下架后，作品从展示页移除，其他成员也无法凭旧链接打开详情、附件预览或下载。

## 展示与下载权限

对普通成员，作品的展示状态决定它能否出现在作品展，下载开关决定原件能否通过站内下载。两项权限分别由服务端检查，附件继承所属作品的规则。

| 操作 | 其他已登录成员 | 作品作者 | 管理员 |
| --- | --- | --- | --- |
| 在作品展看到作品 | 已通过审核且已上架 | 已通过审核且已上架 | 已通过审核且已上架 |
| 打开详情和在线预览 | 已上架作品 | 自己的作品，包括草稿和待审核作品 | 所有作品 |
| 从站内下载原件 | 已上架且开启下载 | 同普通成员 | 可下载原件以完成审核 |
| 审核、上架、下架或调整下载开关 | 无 | 无 | 可操作 |

作品上架但关闭下载时，成员仍可以在线浏览 PPT、PDF，或播放音视频。作品下架时，即使下载开关仍保留为开启，其他成员也无法取得原件。站内下载设置控制平台交付原件的入口。浏览的内容仍可截图或录屏，音视频播放需要把相应的数据传给浏览器。

## PPT 在线浏览

使用 ONLYOFFICE Docs 的只读查看器直接浏览 PPT 与 PPTX 演示文稿，保留原件和幻灯片页结构。Vue 在作品详情内嵌入查看器。上线验收使用真实竞赛文件，检查中文字体、版式、动画、转场和内嵌视频。 [ONLYOFFICE 只读模式](https://api.onlyoffice.com/docs/docs-api/get-started/how-it-works/viewing) · [支持的演示文稿格式](https://api.onlyoffice.com/docs/docs-api/usage-api/config/document)

原件存放在私有存储。应用检查作品查看权限后发放短期预览配置。ONLYOFFICE Docs 在独立服务网络中凭出站请求签名取件，取件接口再次校验账号和作品权限。查看器的下载、打印和复制入口关闭，站内原件下载统一走作品的下载权限。 [查看器权限](https://api.onlyoffice.com/docs/docs-api/usage-api/config/document/permissions) · [出站请求签名](https://api.onlyoffice.com/docs/docs-api/additional-api/signature/request/token-in-header)

## PDF、音视频与源码

PDF 在线预览由后端按需渲染单页并返回页面图像。PDF 原件通过作品下载接口交付。平台支持未加密且含页面的 PDF。

视频支持 MP4 和 WebM，音频支持 MP3。音视频使用支持范围请求的预览接口播放。源码以 ZIP 作为作品附件保存。启用下载时，成员可以取得对应原件。

## 技术与部署

前端沿用 Vue 3。后端采用 Django 5.2 LTS 和 Django REST Framework，管理端优先用 Django Admin。正式数据库使用 MySQL 8.4 LTS，本地开发可以先用 SQLite。文件与数据库分开存放，演示文稿查看器作为独立服务接入。 [Django 5.2](https://docs.djangoproject.com/en/5.2/releases/5.2/) · [Django 的 MySQL 支持](https://docs.djangoproject.com/en/5.2/ref/databases/#mysql-notes)

## 实现顺序与验收

| 阶段 | 验收结果 |
| --- | --- |
| 1. 账号与会话 | 初始管理员能创建、重设和回收普通账号。回收后旧会话失效。未登录用户先进入登录页。 |
| 2. 投稿、审核和作品权限 | 一件作品可添加多个附件并一次提交。管理员能退回并填写意见、通过审核、上架和切换下载。测试未上架访问及直接文件链接。 |
| 3. 作品详情和在线预览 | 同一详情可切换演示文稿、PDF、音视频和源码附件。PPT 与 PPTX 通过真实查看服务打开。下载按钮与作品权限一致。 |
| 4. 部署验收 | 在 MySQL、私有文件存储和 ONLYOFFICE Docs 环境跑通管理员发账号、成员投稿、审核上架、权限变更和账号回收。 |
